# The public surface of tehas 2.x, from 2.0, one name per line: the
# commands and subcommands of api/commands.txt and their public flags, the
# settings and roles of api/settings-rules.json, the labels of
# host/labels.tsv, the fields of the --json objects of api/*.schema.json,
# an array's items written `[]`, and the tools of the read-only MCP server
# and their arguments and answer fields, written `tool <name>`,
# `tool <name> arg <arg>` and `tool <name> answer <field>`, all read from
# the server's own tool table, its input schemas and its output schemas.
# A feature still being built is not here, nor
# are the flags api/commands.txt marks internal or the fields under those
# host/docs/contract.md says may change. A name that was here before its
# feature became building stays, and a release refuses it while the feature
# is building.
#
# Lines are only added, at the end, in the release that brings the name.
# From v2.0.0-beta.1 none is taken out or changed within 2.x.
# console/tests/surface.rs fails when the surface loses a
# name of this file, and when it has one this file does not list yet.
