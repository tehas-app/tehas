# The tehas commands, their subcommands and the flags each takes, one line per
# command and one per subcommand, in order: the command, the subcommand, its
# flags, then two marks. `building=<feature>` marks a command of a feature
# still being built, which is not public until that feature ships, and
# `--flag:building=<feature>` marks one flag of such a feature the same way.
# `internal=<flag>,...` marks flags that a unit or the dashboard writes, not a
# person or a program; they are not public. Within 1.x a public command,
# subcommand or flag is only added. The tests of console/src/front.rs hold
# this list to the commands tehas knows and to the synopsis lines of each
# command's text, so a row or a flag added or taken out without this file
# fails the gate. `--help` is every command's and is not listed.
