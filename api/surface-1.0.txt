# settings and roles of api/settings-rules.json, the labels of
# host/labels.tsv and the fields of the --json objects of api/*.schema.json,
# an array's items written `[]`. A feature still being built is not here, nor
# are the flags api/commands.txt marks internal or the fields under those
# host/docs/contract.md says may change.
#
# Lines are only added, at the end, in the release that brings the name.
# None is taken out or changed within 1.x. console/tests/surface.rs fails
# when the surface loses a name of this file, and when it has one this file
# does not list yet.
