# Previews and the shared edge: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every open pull request of the product gets a locked-down container at `uat-<pr>.<domain>`, the Protolab moves to `lab-<issue>.<domain>`, and one router container serves both.

**Architecture:** One Caddy router with a fixed config picks the target from the first label of the Host header: files for `lab-<n>`, a reverse proxy to the container `tehas-preview-<n>` for `uat-<n>`. `tehasbot preview` runs every five minutes, builds an image from `preview/Dockerfile` in the pull request's commit, and removes what is no longer open. `tehasbot preview --sweep` runs every three hours and removes leftovers starting from what is on the host.

**Tech Stack:** bash (`set -uo pipefail`), jq, git, gh, docker, Caddy 2.8.4, systemd user units. Tests are shell, with `t_stub` from `test/lib.sh`.

**Spec:** `docs/specs/2026-10-10-previews.md`. Read it first. Work in the worktree `/home/janit/work/tehas-previews`, branch `previews`.

## Global Constraints

- Platform files name no product and no host. No private address anywhere: `scripts/check-generic.sh` refuses them. Examples use `example.org` and `192.0.2.x`; the manual may use the tehas-tehas instance and `tehas.app`.
- A command fails closed: a missing or malformed setting is exit 78 before `gh`, `docker` or `git` is called and before anything is written.
- `lib/config.sh` has no side effects and `tehas_load` never exits.
- `libexec/work` and `test/work_test.sh` are not touched. A cycle's container is given nothing new.
- A pull request whose `head.repo.full_name` is not `TEHAS_REPO` is never built. Do not relax that test.
- Do not edit `.pi/`, `AGENTS.md`, `scripts/verify.sh`, `scripts/check-generic.sh`, or anything under `instances/` except `instances/example/`.
- Bash: two spaces, `shellcheck -x` clean, no blanket disables. A header comment gives what the command does, its usage and its exit statuses. Comments say why.
- Prose in comments, the manual and commit messages: plain, short sentences, no em dashes.
- The manual in `host/docs/` changes in the same commit as the behaviour it describes.
- One logical change per commit, subject as a short statement, no issue numbers. Commit before reporting a task done.
- Run `scripts/verify.sh` at the end of every task. Expected: every line starts with `ok`.
- Names, exactly: container `tehas-preview-<n>`, image `tehas-preview:<n>`, network `tehas-previews` (internal), compose project `tehas-edge`, labels `tehas.preview`, `tehas.sha`, `tehas.repo`, recipe `preview/Dockerfile`, port 8080 in a preview, port 8081 for the router.

## Review Focus

1. **GitHub answers with an empty list by mistake.** Every preview is removed and rebuilt at the next run. Expected: a failed or malformed answer removes nothing. Pinned in Task 5 ("GitHub down removes nothing", "an answer that is not a list removes nothing").
2. **A branch is force-pushed while its build runs.** Expected: the container is labelled with the commit that was built, and the next run builds the new one. Pinned in Task 5 ("the label is the commit that was fetched").
3. **A stranger writes a comment that starts with the bot's marker.** Expected: the bot edits only its own comment and posts one of its own. Pinned in Task 7.
4. **`df` or `docker info` gives no figure.** Expected: no build, state `no-space` with a reason that says the space could not be read; nothing is removed that would not be otherwise. Pinned in Task 6.
5. **A sweep runs while GitHub is rate-limited.** Expected: an answer that is not a clear "open", "closed" or 404 keeps everything. Pinned in Task 8.

```bash
# shellcheck shell=bash
# What tehasbot protolab and tehasbot preview both do with a numbered set
# under $TEHAS_HOME: a ticket's pages, a pull request's preview. Sourced, not
# run. It needs TEHAS_HOME and calls nothing but the shell's own tools and
# flock.
#
#   edge_lock <name> [<seconds>]   one run at a time
#   edge_put <file> <command...>   a file that is whole or not there
#   edge_place <new> <place>       a directory that is whole or the old one
#   edge_numbers <directory>       the numbered directories in it

# edge_lock <name> [<seconds to wait>]: take $TEHAS_HOME/state/<name>.lock
# until this process ends. Returns 1 when another process holds it.
edge_lock() {
  mkdir -p "$TEHAS_HOME/state" || return 1
  exec 9>"$TEHAS_HOME/state/$1.lock" || return 1
  if [ -n "${2:-}" ]; then flock -w "$2" 9; else flock -n 9; fi
}

# edge_put <file> <command...>: the command's output becomes the file. A
# server may read the file at any moment, so it is written beside itself and
# renamed. A command that fails leaves the file as it was.
edge_put() {
  local file=$1
  shift
  if ! "$@" >"$file.new"; then
    rm -f "$file.new"
    return 1
  fi
  mv "$file.new" "$file"
}

# edge_place <new directory> <place>: the new one takes the place by rename.
# The old one is moved aside first and removed afterwards, so there is no
# moment with a half-copied directory.
edge_place() {
  local new=$1 place=$2 old
  old=$(dirname "$place")/.old
  rm -rf "$old"
  if [ -d "$place" ]; then mv "$place" "$old" || return 1; fi
  mv "$new" "$place" || return 1
  rm -rf "$old"
}

# edge_numbers <directory>: its subdirectories whose name is a number.
edge_numbers() {
  local dir n
  for dir in "$1"/*/; do
    [ -d "$dir" ] || continue
    n=$(basename "$dir")
    case "$n" in *[!0-9]* | "") continue ;; esac
    echo "$n"
  done
  return 0
}
```

```
# The edge router: one server for everything tehas publishes by name. Plain
# HTTP, bound to the instance's TEHAS_HOST_ADDR in router.compose.yaml; the
# proxy in front of the host carries the certificate.
#
# It picks by the first label of the Host header, so no domain is written here:
#   uat-<number>.   the preview of that pull request, a container named
#                   tehas-preview-<number> that `tehasbot preview` runs
#   lab-<number>.   that ticket's page in the Protolab and its files, as
#                   `tehasbot protolab` wrote them
#   anything else   the Protolab by path: the list at /, a ticket at /<number>/
#
# This file is fixed. Nothing writes it when a preview comes or goes: Docker's
# own name lookup finds the container, and a name it does not find is a 404.
#
# It is a server of its own, apart from the dashboard, because a prototype and
# a preview are somebody's HTML and script.
{
    auto_https off
    admin off
}
:8081 {
    header X-Robots-Tag "noindex, nofollow"
    header X-Content-Type-Options "nosniff"

    @preview header_regexp preview Host ^uat-([1-9][0-9]{0,8})\.
    @ticket header_regexp ticket Host ^lab-([1-9][0-9]{0,8})\.
    # A uat- or lab- name that is neither of the above: no number, or one
    # that starts with a zero.
    @odd header_regexp odd Host ^(uat|lab)-
    @look path /fun/*.css /fun/*.ttf /fun/*.svg
    @kept path */.*
    @hostfiles path /files/*
    @pathfiles path_regexp ^/[0-9]+/files/.

    route {
        # A preview answers for itself. What it says about indexing and
        # sniffing is dropped: this server has already said it.
        handle @preview {
            reverse_proxy tehas-preview-{re.preview.1}:8080 {
                header_down -X-Robots-Tag
                header_down -X-Content-Type-Options
            }
        }

        # From here on, the Protolab.
        header Referrer-Policy "no-referrer"
        # The pages are rebuilt in place; a browser asks again every time.
        header Cache-Control "no-cache"
        # What `tehasbot protolab` keeps for itself: stamps, lists, work in progress.
        respond @kept 404
        # The typeface, the style sheets and the sprites, shared with the
        # dashboard. Its page and its scripts stay there.
        handle @look {
            uri strip_prefix /fun
            root * /srv/fun
            file_server
        }
        # One ticket under a name of its own, so one prototype's script is a
        # stranger to another's.
        handle @ticket {
            root * /srv/protolab/{re.ticket.1}
            # A ticket's files, served as they are. The sandbox gives each one
            # an origin with nothing in it. Scripts may run.
            handle @hostfiles {
                header Content-Security-Policy "sandbox allow-scripts allow-forms allow-modals allow-pointer-lock"
                # A sandboxed page asks for its own scripts and data as a stranger.
                header Access-Control-Allow-Origin "*"
                file_server
            }
            # The page `tehasbot protolab` wrote: no script, nothing from elsewhere.
            handle {
                header Content-Security-Policy "default-src 'none'; style-src 'self'; img-src 'self' data:; media-src 'self'; font-src 'self'; frame-src 'self'; base-uri 'none'; form-action 'none'"
                file_server
            }
        }
        handle @odd {
            respond "No such address." 404
        }
        # The Protolab by path: its list, and every ticket for a host that has
        # no domain for the edge.
        handle {
            root * /srv/protolab
            handle @pathfiles {
                header Content-Security-Policy "sandbox allow-scripts allow-forms allow-modals allow-pointer-lock"
                header Access-Control-Allow-Origin "*"
                file_server
            }
            handle {
                header Content-Security-Policy "default-src 'none'; style-src 'self'; img-src 'self' data:; media-src 'self'; font-src 'self'; frame-src 'self'; base-uri 'none'; form-action 'none'"
                file_server
            }
        }
    }
    handle_errors {
        # No container of that name, or one that does not answer.
        @nopreview expression `{err.status_code} in [502, 503, 504]`
        respond @nopreview "No preview is running at this address. One is built within five minutes of a push to a pull request, and removed when the pull request is closed." 404
        respond "{err.status_code} {err.status_text}" {err.status_code}
    }
}
```

```bash
#!/usr/bin/env bash
# Keep a running preview of every open pull request: a container that serves
# the product as that pull request has it, reached through the edge router as
# uat-<number>.<TEHAS_DOMAIN> (edge/router.Caddyfile).
#
#   which ones      Open pull requests whose head branch is in the product
#                   repository itself. Pushing there needs write access. A
#                   pull request from a fork is never built.
#   what it is      The image that preview/Dockerfile of that commit builds,
#                   answering HTTP on port 8080. A commit without that file
#                   has no preview.
#   what it gets    Nothing of the host: no mount, no variable, no port, no
#                   token, a read-only root, and a network on which only the
#                   router is. The build gets the commit as an archive on
#                   standard input and nothing else.
#   how many        The newest TEHAS_PREVIEW_MAX. The rest say "over-limit".
#   when it goes    At the next run after the pull request is merged or
#                   closed: the container, the image, the fetched ref and
#                   the state.
#
# Each pull request has a state in $TEHAS_HOME/preview/<number>/state.json:
# serving, building, no-recipe, build-failed, no-space or over-limit. The list
# for the dashboard is $TEHAS_HOME/live/previews.json. A build's output is in
# $TEHAS_HOME/logs/preview-<number>.log. Deterministic, no model.
#
# Usage: tehasbot preview            bring the previews in step with the pull requests
#        tehasbot preview --sweep    the three hour check of what is left on the host
#
# Exit: 0 done, or GitHub or Docker did not answer and what runs was left
#       running; 1 it cannot write under $TEHAS_HOME; 64 a wrong argument;
#       78 the instance settings are invalid or TEHAS_PREVIEWS is not 1.
set -uo pipefail
umask 022

here=$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)
# shellcheck source=lib/config.sh
. "$here/../lib/config.sh"
# shellcheck source=lib/edge.sh
. "$here/../lib/edge.sh"

mode=run
case "${1:-}" in
  "") ;;
  --sweep) mode=sweep ;;
  *)
    echo "usage: tehasbot preview [--sweep]" >&2
    exit 64
    ;;
esac

tehas_load || exit 78
tehas_require TEHAS_REPO
if [ "$TEHAS_PREVIEWS" != 1 ]; then
  tehas_err "TEHAS_PREVIEWS is not 1: this instance has no previews"
  exit 78
fi

repo=$TEHAS_REPO
root=$TEHAS_HOME/preview
bare=$root/repo.git
live=$TEHAS_HOME/live
logs=$TEHAS_HOME/logs
net=tehas-previews
recipe=preview/Dockerfile
build_limit=900
min_kb=$((TEHAS_PREVIEW_MIN_FREE_MB * 1024))
free=""
low=false

mkdir -p "$root" "$live" "$logs" || exit 1
# The sweep waits for a run to end; a run does not wait for anything.
if [ "$mode" = sweep ]; then
  edge_lock preview 1800 || { echo "the lock was not free in 30 minutes, nothing was swept"; exit 0; }
else
  edge_lock preview || { echo "another tehasbot preview is running"; exit 0; }
fi

# --- The state of one pull request -------------------------------------------
field() { jq -r --arg k "$2" '.[$k] // ""' "$root/$1/state.json" 2>/dev/null; }
# mark <number> <commit> <state> [reason]: written only when it differs, so
# "time" is when the state began.
mark() {
  local n=$1 sha=$2 state=$3 reason=${4:-} pull=$root/$1/pull.json
  if [ "$(field "$n" sha)" = "$sha" ] && [ "$(field "$n" state)" = "$state" ]; then return 0; fi
  mkdir -p "$root/$n" || return 1
  [ -f "$pull" ] || echo '{}' >"$pull"
  edge_put "$root/$n/state.json" jq -n --argjson n "$n" --arg sha "$sha" --arg state "$state" \
    --arg reason "$reason" --arg now "$(date -u +%FT%TZ)" --slurpfile pull "$pull" '
    {number: $n, sha: $sha, state: $state, reason: $reason, time: $now,
     title: ($pull[0].title // ""), url: ($pull[0].url // null)}' || return 1
  echo "#$n: $state${reason:+ ($reason)}"
}

# --- Docker ------------------------------------------------------------------
serving() { # <number> <commit>: is a container of that commit running?
  [ -n "$(docker ps --quiet --filter "name=^tehas-preview-$1\$" --filter "label=tehas.sha=$2" 2>/dev/null)" ]
}
stop() { # <number>: the container and the image
  docker rm -f "tehas-preview-$1" >/dev/null 2>&1
  docker image rm -f "tehas-preview:$1" >/dev/null 2>&1
  return 0
}
purge() { # <number>: everything of one pull request
  stop "$1"
  git -C "$bare" update-ref -d "refs/preview/$1" 2>/dev/null
  rm -rf "${root:?}/$1" "$logs/preview-$1.log"
}

# --- Free space --------------------------------------------------------------
# free_kb: the free kilobytes of the host. Task 6 measures; until then there
# is always room.
free_kb() { echo $((min_kb * 8)); }

# --- The comment on the pull request -----------------------------------------
# comment <number>: Task 7 writes it.
comment() { return 0; }

# --- One build ---------------------------------------------------------------
# build <number>: fetch the pull request's head, build its recipe, replace the
# container. The commit is the one fetched, which is the one built.
build() {
  local n=$1 sha log=$logs/preview-$1.log old
  if [ ! -d "$bare" ]; then
    git init -q --bare "$bare" || return 1
    # The product checkout knows the address and how to sign in to it.
    git -C "$bare" remote add origin \
      "$(git -C "${TEHAS_WORK_REPO:-/nonexistent}" config --get remote.origin.url 2>/dev/null ||
        echo "https://github.com/$repo.git")" || return 1
  fi
  : >"$log"
  if ! git -C "$bare" fetch --quiet --no-tags origin "+refs/pull/$n/head:refs/preview/$n" >>"$log" 2>&1; then
    mark "$n" "$2" build-failed "The commit could not be fetched."
    return 1
  fi
  sha=$(git -C "$bare" rev-parse --verify --quiet "refs/preview/$n^{commit}") || return 1
  if ! git -C "$bare" cat-file -e "$sha:$recipe" 2>/dev/null; then
    stop "$n"
    mark "$n" "$sha" no-recipe "The commit has no $recipe."
    return 0
  fi
  mark "$n" "$sha" building
  old=$(docker image inspect --format '{{.Id}}' "tehas-preview:$n" 2>/dev/null) || old=""
  if ! git -C "$bare" archive "$sha" | timeout "$build_limit" docker build --quiet \
    -f "$recipe" -t "tehas-preview:$n" \
    --label "tehas.preview=$n" --label "tehas.sha=$sha" --label "tehas.repo=$repo" - >>"$log" 2>&1; then
    mark "$n" "$sha" build-failed "The build failed or ran over $((build_limit / 60)) minutes. Its output is in logs/preview-$n.log on the host."
    return 1
  fi
  # The same name cannot run twice, so the old container goes first. It is a
  # few seconds of the router's 404.
  docker rm -f "tehas-preview-$n" >/dev/null 2>&1
  if ! docker run --detach --name "tehas-preview-$n" --network "$net" \
    --read-only --tmpfs /tmp --tmpfs /config --tmpfs /data \
    --cap-drop ALL --cap-add NET_BIND_SERVICE --security-opt no-new-privileges:true \
    --memory 256m --cpus 1 --pids-limit 128 --restart unless-stopped \
    --label "tehas.preview=$n" --label "tehas.sha=$sha" --label "tehas.repo=$repo" \
    "tehas-preview:$n" >>"$log" 2>&1; then
    mark "$n" "$sha" build-failed "The container did not start. See logs/preview-$n.log on the host."
    return 1
  fi
  if [ -n "$old" ] && [ "$old" != "$(docker image inspect --format '{{.Id}}' "tehas-preview:$n" 2>/dev/null)" ]; then
    docker image rm "$old" >/dev/null 2>&1
  fi
  mark "$n" "$sha" serving
}

# --- The list for the dashboard ----------------------------------------------
write_list() {
  local files=() f sweep=$root/sweep.json
  for f in "$root"/*/state.json; do
    [ -f "$f" ] && files+=("$f")
  done
  [ -f "$sweep" ] || sweep=/dev/null
  edge_put "$live/previews.json" jq -s --arg now "$(date -u +%FT%TZ)" --arg domain "$TEHAS_DOMAIN" \
    --arg free "$free" --argjson min "$min_kb" --argjson low "$low" --slurpfile sweep "$sweep" '
    {generatedAt: $now,
     disk: {freeBytes: (if $free == "" then null else ($free | tonumber) * 1024 end),
            minFreeBytes: ($min * 1024), low: $low},
     lastSweep: ($sweep[0] // null),
     previews: (sort_by(-.number) | map(. + {address:
       (if .state == "serving" then "https://uat-\(.number).\($domain)/" else null end)}))}' \
    "${files[@]}" </dev/null
}

# --- The five minute run -----------------------------------------------------
run() {
  local pulls ours pr n sha i=0 open=" " wanted=() elsewhere have item
  if ! docker info --format '{{.DockerRootDir}}' >/dev/null 2>&1; then
    echo "Docker does not answer; nothing was built or removed"
    return 0
  fi
  docker network inspect "$net" >/dev/null 2>&1 || docker network create --internal "$net" >/dev/null 2>&1

  if free=$(free_kb); then
    [ "$free" -ge "$min_kb" ] || low=true
  else
    free=""
    low=true
  fi

  pulls=$(gh api "repos/$repo/pulls?state=open&sort=created&direction=desc&per_page=100" 2>/dev/null) ||
    { write_list; return 0; }
  # Ours: a number, a commit id, and a head in this repository and no other.
  ours=$(jq -c --arg repo "$repo" '
    if type != "array" then error("not a list") else . end
    | map(select((.number | type) == "number" and .number > 0
                 and ((.head.sha // "") | test("^[0-9a-f]{40}$"))
                 and ((.head.repo.full_name // "") | ascii_downcase) == ($repo | ascii_downcase))
          | {number, sha: .head.sha, title: ((.title // "") | .[0:180]), url: (.html_url // null)})
    | .[]' <<<"$pulls" 2>/dev/null) || { write_list; return 0; }
  elsewhere=$(jq --arg repo "$repo" '
    [.[] | select(((.head.repo.full_name // "") | ascii_downcase) != ($repo | ascii_downcase))] | length' \
    <<<"$pulls" 2>/dev/null) || elsewhere=0
  if [ "$elsewhere" = 1 ]; then
    echo "1 pull request from elsewhere, not built"
  elif [ "$elsewhere" != 0 ]; then
    echo "$elsewhere pull requests from elsewhere, not built"
  fi

  while IFS= read -r pr; do
    [ -n "$pr" ] || continue
    n=$(jq -r .number <<<"$pr")
    sha=$(jq -r .sha <<<"$pr")
    open="$open$n "
    mkdir -p "$root/$n" || return 1
    edge_put "$root/$n/pull.json" jq -c '{title, url}' <<<"$pr" || return 1
    i=$((i + 1))
    if [ "$i" -gt "$TEHAS_PREVIEW_MAX" ]; then
      stop "$n"
      mark "$n" "$sha" over-limit "More than $TEHAS_PREVIEW_MAX pull requests are open."
      continue
    fi
    wanted+=("$n $sha")
  done <<<"$ours"

  # What is on the host and no longer open: by directory and by container.
  have=$({
    edge_numbers "$root"
    docker ps -a --filter label=tehas.preview \
      --format '{{.ID}} {{.Label "tehas.preview"}} {{.Label "tehas.repo"}}' 2>/dev/null | awk '{print $2}'
  } | grep -E '^[1-9][0-9]*$' | sort -un)
  while IFS= read -r n; do
    [ -n "$n" ] || continue
    case "$open" in *" $n "*) continue ;; esac
    purge "$n"
    echo "#$n: pull request no longer open, removed"
  done <<<"$have"

  for item in "${wanted[@]+"${wanted[@]}"}"; do
    n=${item%% *}
    sha=${item#* }
    if serving "$n" "$sha"; then
      mark "$n" "$sha" serving
    elif [ "$(field "$n" sha)" = "$sha" ] && case "$(field "$n" state)" in build-failed | no-recipe) true ;; *) false ;; esac; then
      : # that commit was tried; a new one is tried again
    elif [ "$low" = true ]; then
      no_space "$n" "$sha"
    else
      build "$n" "$sha"
    fi
    comment "$n"
  done
  write_list
}

# no_space <number> <commit>: Task 6 writes the reason.
no_space() { mark "$1" "$2" no-space "The host is low on disk."; }

# --- The three hour check ----------------------------------------------------
# Task 8 writes it.
sweep() {
  echo "usage: tehasbot preview" >&2
  exit 64
}

case "$mode" in
  run) run || exit 1 ;;
  sweep) sweep || exit 1 ;;
esac
exit 0
```

```bash
# --- The three hour check ----------------------------------------------------
# The five minute run removes what GitHub's list of open pull requests no
# longer has. This does not trust that list or that run. It starts from what
# is on the host, asks GitHub about each pull request by itself, and removes
# what is merged, closed, not there or not ours. An answer that is not clear
# keeps everything: a sweep never removes on a failed call.
sweep() {
  local removed=0 numbers n id tag owner answer err verdict
  if ! docker info --format '{{.DockerRootDir}}' >/dev/null 2>&1; then
    echo "Docker does not answer; nothing was swept"
    return 0
  fi

  # Containers that carry the label and are no pull request of this repository.
  while read -r id n owner; do
    [ -n "$id" ] || continue
    if [[ $n =~ ^[1-9][0-9]*$ ]] && [ "$owner" = "$repo" ]; then continue; fi
    docker rm -f "$id" >/dev/null 2>&1
    echo "container $id: swept, it belongs to no pull request of $repo"
    removed=$((removed + 1))
  done < <(docker ps -a --filter label=tehas.preview \
    --format '{{.ID}} {{.Label "tehas.preview"}} {{.Label "tehas.repo"}}' 2>/dev/null)

  # Images: one that is not tagged for a number is what a rebuild left, and
  # one of another repository is not ours. Docker refuses to remove an image a
  # container runs, which is the wanted answer.
  while read -r id tag; do
    [ -n "$id" ] || continue
    owner=$(docker image inspect --format '{{index .Config.Labels "tehas.repo"}}' "$id" 2>/dev/null)
    if [[ $tag =~ ^tehas-preview:[1-9][0-9]*$ ]] && { [ -z "$owner" ] || [ "$owner" = "$repo" ]; }; then continue; fi
    if docker image rm "$id" >/dev/null 2>&1; then
      echo "image $id: swept, it belongs to no preview"
      removed=$((removed + 1))
    fi
  done < <(docker image ls --filter label=tehas.preview --format '{{.ID}} {{.Repository}}:{{.Tag}}' 2>/dev/null)

  numbers=$({
    edge_numbers "$root"
    docker ps -a --filter label=tehas.preview \
      --format '{{.ID}} {{.Label "tehas.preview"}} {{.Label "tehas.repo"}}' 2>/dev/null |
      awk -v repo="$repo" '$3 == repo {print $2}'
    docker image ls --filter label=tehas.preview --format '{{.ID}} {{.Repository}}:{{.Tag}}' 2>/dev/null |
      sed -n 's/^[^ ]* tehas-preview:\([0-9]*\)$/\1/p'
    [ ! -d "$bare" ] || git -C "$bare" for-each-ref --format='%(refname)' refs/preview 2>/dev/null | sed 's|.*/||'
  } | grep -E '^[1-9][0-9]*$' | sort -un)

  err=$(mktemp "$TEHAS_HOME/tmp/preview-sweep.XXXXXX" 2>/dev/null) || err=/dev/null
  while IFS= read -r n; do
    [ -n "$n" ] || continue
    verdict=keep
    if answer=$(gh api "repos/$repo/pulls/$n" 2>"$err"); then
      verdict=$(jq -r --arg repo "$repo" '
        if (.state | type) != "string" then "unclear"
        elif .state != "open" then "closed"
        elif ((.head.repo.full_name // "") | ascii_downcase) != ($repo | ascii_downcase) then "elsewhere"
        else "keep" end' <<<"$answer" 2>/dev/null) || verdict=unclear
    elif grep -q 'HTTP 404' "$err" 2>/dev/null; then
      verdict=gone
    else
      verdict=unclear
    fi
    case "$verdict" in
      keep) ;;
      closed) purge "$n"; echo "#$n: swept, the pull request is closed"; removed=$((removed + 1)) ;;
      gone) purge "$n"; echo "#$n: swept, there is no such pull request"; removed=$((removed + 1)) ;;
      elsewhere) purge "$n"; echo "#$n: swept, its branch is not in $repo"; removed=$((removed + 1)) ;;
      *) echo "#$n: no answer from GitHub, kept" ;;
    esac
  done <<<"$numbers"
  [ "$err" = /dev/null ] || rm -f "$err"

  edge_put "$root/sweep.json" jq -n --arg now "$(date -u +%FT%TZ)" --argjson removed "$removed" \
    '{time: $now, removed: $removed}' || return 1
  if free=$(free_kb); then
    [ "$free" -ge "$min_kb" ] || low=true
  else
    free=""
    low=true
  fi
  write_list
}
```

````markdown
# Previews and the Protolab on the internet

A host can publish two things under names of their own: a running preview of
every open pull request, and the Protolab's page for every ticket at the
prototype stage. This page is how that was set up for the tehas-tehas
instance, written so that another instance can follow it.

| Name | What answers |
| --- | --- |
| `uat-<pr>.tehas.app` | The preview of that pull request |
| `lab-<issue>.tehas.app` | That ticket's page in the Protolab |
| `lab.tehas.app` | The Protolab's list |

How far this is proven: the steps for the domain and the proxy were carried out
and checked on 10 October 2026, on Ubuntu 26.04 LTS with Caddy 2.11 as a system
service. The router and `tehasbot preview` are covered by the shell tests and
are not yet proven on a host. See [Features](/features).

## What it needs

- A domain whose DNS is at Cloudflare, proxied, with a wildcard record. The
  dashboard's own name is already there in the same way.
- A proxy in front of the host that can reach the host's private address. For
  tehas-tehas that is a Caddy on another machine, the one that already sends
  `tehas.app` to port 8080.
- Docker on the host, which a tehas host has.

Nothing here needs a DNS token or a paid certificate.

## Why the names are one level deep

Cloudflare's free certificate covers the domain and one level under it:
`*.tehas.app`. A name two levels down, such as `12.uat.tehas.app`, resolves and
then fails at the TLS handshake. You can see both halves:

```
dig +short 1.uat.tehas.app          # answers: the wildcard record matches
curl -sI https://1.uat.tehas.app    # fails: no certificate for two levels
curl -sI https://uat-1.tehas.app    # gets an answer
```

Two levels need Cloudflare's paid certificates, or a DNS token on the host and
the host's address made public. `uat-12.tehas.app` needs neither.

## The proxy needs a certificate too

Cloudflare speaks HTTPS to the proxy in front of the host. A Caddy that gets a
certificate per site has none for a name it has no site for, and Cloudflare
then answers 525. That is what `lab.tehas.app` said before this was set up.

The answer is one certificate for `*.tehas.app` on the proxy. A Cloudflare
origin certificate is free, lasts for years and needs no renewal job. It is
trusted by Cloudflare only, which is enough: these names are only ever reached
through Cloudflare.

### 1. Make the certificate

In Cloudflare, in the domain: **SSL/TLS**, **Origin Server**, **Create
Certificate**.

- Leave "Generate private key and CSR with Cloudflare" chosen.
- Host names: `*.tehas.app` and `tehas.app`, which is the default.
- Validity: the default of 15 years.
- Format: PEM.

The next page shows the certificate and the private key. The key is shown
once. Keep the page open for the next step. On **SSL/TLS**, **Overview**, the
encryption mode has to be Full or Full (strict).

### 2. Put the two files on the proxy's machine

As root there:

```
mkdir -p /etc/caddy/certs
nano /etc/caddy/certs/origin.pem     # the Origin Certificate, with its BEGIN and END lines
nano /etc/caddy/certs/origin.key     # the Private Key, the same
chown -R caddy:caddy /etc/caddy/certs
chmod 700 /etc/caddy/certs
chmod 644 /etc/caddy/certs/origin.pem
chmod 600 /etc/caddy/certs/origin.key
```

### 3. Check the files before touching the Caddyfile

```
openssl x509 -in /etc/caddy/certs/origin.pem -noout -ext subjectAltName -enddate
sudo -u caddy test -r /etc/caddy/certs/origin.key && echo "caddy can read the key"
```

The first lists both host names and an end date years away. The second prints
its line.

> **The files come first.** A site that names certificate files that are not
> there stops Caddy from starting at all. If Caddy is then restarted, every
> site in that Caddyfile is down, not only the new one. This happened while
> these steps were first taken. To get back: take the new site out,
> `caddy validate --config /etc/caddy/Caddyfile`, `systemctl start caddy`.

### 4. Add the site

Under the dashboard's site in `/etc/caddy/Caddyfile`, with the host's private
address in place of `<address>`:

```
*.tehas.app {
    tls /etc/caddy/certs/origin.pem /etc/caddy/certs/origin.key
    @edge header_regexp Host ^(lab|lab-[0-9]+|uat-[0-9]+)\.tehas\.app$
    handle @edge {
        reverse_proxy <address>:8081
    }
    handle {
        respond 404
    }
}
```

Caddy takes a wildcard as a whole label only, so `lab-*` cannot be a site
address; the matcher picks the names. The sites `tehas.app` and
`www.tehas.app` are more specific and are not touched. The Host header is
passed on as it is, which is what the router picks by.

### 5. Validate, then reload

```
caddy validate --config /etc/caddy/Caddyfile && systemctl reload caddy
```

Reload, never restart. A reload with a configuration Caddy refuses keeps the
old one serving. Warnings about formatting or deprecated directives elsewhere
in the file do not matter; the last line has to be `Valid configuration`.

### 6. What the names answer now

| Name | Answer | It means |
| --- | --- | --- |
| `tehas.app` | 200 | The dashboard is as before |
| `www.tehas.app` | 301 | So is its redirect |
| `lab.tehas.app`, `lab-1.tehas.app`, `uat-1.tehas.app` | 502 | The certificate and the site work. Nothing listens on port 8081 of the host yet |
| `nothing.tehas.app`, `uat-x.tehas.app` | 404 | Other names are refused |
| any of them | 521 | Caddy on the proxy is not running. See the box above |
| any of them | 525 | The certificate is not in place, or the encryption mode is not Full |

```

  printf '%-20s ' "$h"; curl -s -o /dev/null -w '%{http_code}\n' "https://$h"
done
```

### 10. A preview, end to end

The product needs a `preview/Dockerfile`: see [A new project](/new-project).
Push a branch to the product repository and open a pull request. Within five
minutes:

- the bot comments on the pull request with `https://uat-<pr>.tehas.app/`,
- the dashboard lists it under Previews,
- `tail ~/tehas/logs/preview.log` has a line `#<pr>: serving`.

Merge or close it, and within five minutes the log has
`#<pr>: pull request no longer open, removed`, and the name answers 404.

When a preview is not there, the pull request's comment and the dashboard say
why. See [Troubleshooting](/troubleshooting).

## What a preview is given, and what it is not

A preview runs the pull request's own files on the factory's host. It is
given nothing of the host: no directory, no setting, no token, no port, a
read-only root, 256 MB and one CPU. It is on a Docker network with the router
and nothing else, so it cannot reach the internet, the model host or the
dashboard.

Only a pull request whose branch is in the product repository gets one.
Pushing there needs write access. A pull request from a fork never gets one.

## Limits

- A preview is public. A branch pushed to the repository is on the internet
  within five minutes.
- The build runs the pull request's `preview/Dockerfile` on the host's Docker,
  with network access. That is why forks are left out.
- `uat-<pr>.tehas.app` and `tehas.app` are one site to a browser. A preview's
  script can set a cookie for the domain. Nothing on the dashboard logs in, so
  this is accepted today.
- The origin certificate is trusted by Cloudflare only. A browser sent
  straight to the proxy's machine for these names is warned.
- Under `TEHAS_PREVIEW_MIN_FREE` of free disk no preview is built. Docker's
  build cache is not pruned by tehas.
- A full disk does not stop a cycle. Only previews hold back.
````
