# Plugin specification 1.0.0

**Status**: 1.0.0, 2026-11-21. Stamped by the owner's decision: Floorplan,
the spec interview and the page ticket are the three plugins that ship first,
and these files are the whole specification they ship with. Nothing is built
beyond what each file says.

## The files

One specification, read in this order. A later file changes an earlier one
where it says so, in its "Changes to" tables.

specification: the specification's version is the number on this page.

## Revisions

A change of scope after 1.0.0 is a revision: a pull request that changes the
files above and adds a row here. A new capability or surface moves the minor
number (1.1.0). A correction that changes no behaviour moves the patch number
(1.0.1). The manual, `host/docs/plugins.md`, says which revision a release
implements.
