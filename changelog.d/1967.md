### Changes

- `tehas start <issue>` approves one open issue for a start from the host, with no label and no GitHub login. The next poll starts it under the usual rules (the pause, the limit, the slots, blockers, an open pull request, a park and the start order), and the start spends the approval. `tehas start <issue> --clear` withdraws it, and `--json` prints what was recorded. The cycle is recorded with how `host`, and the millwright may rest a retry on it as on a person's label. `tehas api` lists the feature `host-start` (#1967).
- The state store moves to schema 13: the table `host_starts`, and `cycles` rebuilt so a start can be recorded as `host`. `tehas update` migrates it and keeps every row (#1967).
