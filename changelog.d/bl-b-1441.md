### Changes

- A cycle's `progress.json` now says `"from":"bad-result"` when the run left a result file that gives nothing for the issue (another schema version, no JSON, a link, or no entry with the issue's number), instead of reading the same as a run that wrote no result (`"progress"`).
- The cycle's facts no longer read `.pi/work-state` from the current directory when the workspace path is not absolute, as an unset `TEHAS_WORK_DIR` left it.

None.
