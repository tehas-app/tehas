### Changes

- The MCP server can read a shared clone of the product: with `TEHAS_MCP_CHECKOUT` set, a full key gets `factory_git_log`, `factory_git_show` and `factory_git_blame`. The clone is mounted read only and read without running `git` or any program its config names (#2709).

### Adopter action

To use it, keep a full clone of the product on the host, set `TEHAS_MCP_CHECKOUT=<path>` in `~/.config/tehas/env` and restart `tehas-mcp.service`. A shallow clone is refused.
