### Changes

- A cycle's workspace is a clone of the default branch and its own issue's
  branches only. It used to hold every branch the product checkout had fetched,
  so the finished work of other issues sat in the tree beside the one being
  worked, where a command could find it. A clone made for a review takes the
  default branch alone; `tehas dev` still makes a clone of every branch, which is
  the one a person reads at a terminal.
