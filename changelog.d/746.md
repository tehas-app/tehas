### Changes

- A cycle's container, every agent in it and the push check before it, is given the cycle token `GH_CYCLE_TOKEN` from `~/.config/tehas/env` as its `GH_TOKEN`, never the host's own token or the GitHub App's. The app's token directory is no longer mounted into a cycle. Without `GH_CYCLE_TOKEN`, `tehas work` exits 78 before it calls GitHub, Docker or git (#746, part of #51).

### Adopter action

Before you update, make a fine-grained token for the bot account, for the product repository only: Contents, Pull requests and Issues read and write, Metadata read, nothing else. Put it in `~/.config/tehas/env` as `GH_CYCLE_TOKEN=...`. A host updated without it starts no cycle until it is there. Commits, pull requests and comments made from inside a cycle then carry the bot account's name, not the app's.
