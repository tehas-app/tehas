### Changes

- `factory_disk` now answers `stale` when its reading is more than three hours old, and refuses a `disk.json` of another api or one that names no file system instead of serving it as a healthy host.
- The sandbox egress proxy now logs the requests it drops (a head that never came, an upstream write that failed, a failed accept), and tells a name that did not resolve apart from one that resolved to no address.
