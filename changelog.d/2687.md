### Changes

- The product wiki is registered as a feature still being built, `wiki`, with its switch `TEHAS_WIKI`. A release refuses `TEHAS_WIKI=on` with 78. With it on in a test or a lab build, `tehas wiki [--json]` says which wiki build is current and how far it is behind main, in commits and in days or months, and `tehasbot wiki` writes the same to `~/tehas/live/wiki.json` every five minutes. With it on, the page `/wiki` shows the same and links the build at `/wiki/<date>-<hash>/`, and the dashboard links the current build; while it is off they answer 404 and the link is hidden. `tehas wiki build [--full]` asks for a build and `tehas-wiki.timer` asks every night: pi-rukas's `wiki` verb writes the pages in a container with the code read-only and no token, and the host checks them, renders them and moves the build into place. No pinned pi-rukas has the verb yet (#2687).
