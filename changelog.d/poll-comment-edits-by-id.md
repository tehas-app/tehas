### Changes

- The poll's comment read costs a tenth of what it did. It no longer asks every comment for its edit history: it asks only the comments GitHub says were edited, by their ids, and puts each history back where the comment read gave it before. A chunk of ten issues' comments now costs GitHub 1 point instead of 10. What the rules read is unchanged: an edit by an account the start rules do not take, on a marker or `Retry` comment, still holds the start, every edit counting, and a history that cannot be read still holds and ends the poll as unread.
