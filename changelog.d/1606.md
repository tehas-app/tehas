### Changes

- A pull request adds its changelog lines in `changelog.d/<issue>.md`, with `### Changes` and `### Adopter action`, instead of editing `CHANGELOG.md`, so two open pull requests no longer conflict there. `scripts/release-notes.sh Unreleased` shows the fragments' lines in the Unreleased section, ordered by issue number. `scripts/tag-release.sh` counts their Adopter action, shows the collected section with `--dry-run`, and before it tags moves them into the release's section in a pull request from `changelog-<tag>` (`scripts/collect-changelog.sh`). A tagged release's notes are unchanged (#1606).
