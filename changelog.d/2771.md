### Changes

- Every answer of the plugins' gate now carries the same `Permissions-Policy`
  a page does, so a redirect, an error, a file or a framed file no longer
  sends a shorter list than the manual names (#2771).
- The 12 hours a session lasts are now counted from the first sign-in, not
  from each plugin name: opening a second plugin's view takes its session from
  the one you hold and ends with it, so one GitHub sign-in is good for 12
  hours in all rather than about 24 (#2771). Signing in with GitHub again is a
  new sign-in and starts its own 12 hours. Access is still checked every
  10 minutes, and a session still ends after 2 hours unused.
