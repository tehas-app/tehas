### Changes

- `tehas labels` makes the labels from the table compiled into the console and no longer reads `~/tehas/lib/labels.tsv`, so a missing or malformed installed table no longer stops it with 78. It prints one line, `made the tehas labels`, in place of one line per label. A label it cannot make is named with the reason, and the command exits 1. Its words are not contract; its exit status is (#2962).
- `tehas resume`, the label checks of `tehas plan` and `tehas dev`, and the images of a cycle started by hand match a login of `TEHAS_ALLOWED_LABELERS` ignoring ASCII case, as GitHub logins are one account in any case; the login they print is in lower case. 1.4.x matched exact case. The dispatcher still matches in exact case (#2962).
- The user id check ignores ASCII case too: a login that differs from a listed one only in case must carry the id recorded in `state/account-ids`, or it does not count. `tehas update` and `install.sh` record ignoring case: a pair recorded for the login in another case is its pair, so an id that changed stops them as before, and `--accept-id` takes the login in any case (#2962).
