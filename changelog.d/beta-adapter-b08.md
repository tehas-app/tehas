### Changes

- The poll reads the edit history of an issue's body through the GitHub adapter, as its other reads of GitHub go. What the start rules judge is unchanged: every edit after the approval counts, and a history longer than 100 versions holds the issue as changed by `unknown`. A history whose parts do not agree, such as one with a version deleted from it, or one GitHub's answer leaves out or names an error at that issue for, now holds that issue alone the same way, instead of being read as it stood or ending the poll. An edit by a deleted account holds the issue as by `unknown`, as before. A call that fails, an answer that cannot be read, or an error GitHub names no one issue for, such as a repository the token can no longer see, still ends the poll, its line in tehas's words (`ERROR: unreadable edit history of #N: the site could not be reached`).
