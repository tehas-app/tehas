### Changes

- Nine settings have new names: `TEHAS_INDEXING` is `TEHAS_SITE_INDEXING`, `TEHAS_ANALYTICS_SRC` is `TEHAS_SITE_ANALYTICS_SRC`, `TEHAS_ANALYTICS_SITE` is `TEHAS_SITE_ANALYTICS_NAME`, `TEHAS_ANALYTICS_COOKIE` is `TEHAS_SITE_ANALYTICS_COOKIE`, `TEHAS_CONCURRENCY` is `TEHAS_WORKSTREAMS`, `TEHAS_TICKET_CONCURRENCY` is `TEHAS_MAX_CYCLES`, `TEHAS_REFRESH_MAX` is `TEHAS_REFRESH_MAX_PER_PR`, `TEHAS_OWNER` is `TEHAS_ASSIGNEE`, and `TEHAS_INDUSTRY_VERSION` in `~/.config/tehas/env` is `TEHAS_MANAGER_VERSION`. The values are the same.
- Auto sizing is removed: `TEHAS_CONTAINER_MEMORY`, `TEHAS_CYCLE_CPUS` and `TEHAS_CYCLE_CEILING` are gone, `auto` is refused for `TEHAS_MAX_CYCLES` and `TEHAS_SLICE_CONTAINERS`, and `tehas status --json` no longer has `room.slots`.
- `TEHAS_BOT_LOGIN`, `TEHAS_MILLWRIGHT_LOGIN` and `TEHAS_GITHUB_APP_INSTALLATION` were ignored with a warning and are now refused: the GitHub App gives both logins and the installation is looked up.
- Every setting row of `api/renames-1.0.tsv` still set in `instance.env` or `~/.config/tehas/env` stops every command with 78 and a line that names the new key or why the old one went. `tehas update` and `tehas update --check` list every such line before anything is installed and install nothing until the instance is clean.
- The health file's `checks.industry` is `checks.manager`, the MCP tool `factory_status` serves `manager` in place of `industry`, and the front page footer says `manager vX.Y.Z`.

### Adopter action

Before you update, edit `instance.env`: rename `TEHAS_INDEXING=` to `TEHAS_SITE_INDEXING=`, `TEHAS_ANALYTICS_SRC=` to `TEHAS_SITE_ANALYTICS_SRC=`, `TEHAS_ANALYTICS_SITE=` to `TEHAS_SITE_ANALYTICS_NAME=`, `TEHAS_ANALYTICS_COOKIE=` to `TEHAS_SITE_ANALYTICS_COOKIE=`, `TEHAS_CONCURRENCY=` to `TEHAS_WORKSTREAMS=`, `TEHAS_TICKET_CONCURRENCY=` to `TEHAS_MAX_CYCLES=`, `TEHAS_REFRESH_MAX=` to `TEHAS_REFRESH_MAX_PER_PR=` and `TEHAS_OWNER=` to `TEHAS_ASSIGNEE=`. Take out any `TEHAS_CONTAINER_MEMORY`, `TEHAS_CYCLE_CPUS`, `TEHAS_CYCLE_CEILING`, `TEHAS_BOT_LOGIN`, `TEHAS_MILLWRIGHT_LOGIN` and `TEHAS_GITHUB_APP_INSTALLATION` lines. In `~/.config/tehas/env`, rename `TEHAS_INDUSTRY_VERSION=` to `TEHAS_MANAGER_VERSION=`, and have the program that manages the factory write the new name. A program that reads `checks.industry` or `factory_status.industry` reads `manager` instead. `tehas update --check` lists every line still to change.
