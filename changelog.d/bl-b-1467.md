### Changes

- `factory_disk` now answers `stale` (true when the published reading is more than three hours old) and refuses a `disk.json` that is not a whole answer: not of API 1, with no `generatedAt`, or naming no file system. It used to serve an old or truncated file as a current, healthy host.
- The egress proxy now logs the connections it gives up on: a request head that never ended, a host that did not resolve or resolved to no address, a tunnel that could not be started, and a run of failed accepts. These used to leave nothing in `docker logs tehas-egress`.
