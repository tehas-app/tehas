### Changes

- A factory with outsource on runs a model proxy: a contractor asks it for the
  model with the job's token, and the factory forwards to the endpoint it has
  configured. The real key never leaves the factory, and the proxy passes a
  streamed reply as it arrives, counts tokens per contractor and per job,
  forwards only the model paths a cycle needs, and never logs a body.

### Adopter action

Turn it on with `TEHAS_OUTSOURCE=1` and set `TEHAS_OUTSOURCE_ADDR` to the
address the proxy listens on; its idle timeout
(`TEHAS_OUTSOURCE_IDLE`) must be longer than the check-in timeout
(`TEHAS_OUTSOURCE_TIMEOUT`). Nothing starts until both are set, and a
malformed one stops the command with exit 78.
