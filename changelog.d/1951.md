### Changes

- The overlap hold is gone, with its setting `TEHAS_OVERLAP_HOLD` and the store verb `paths-overlap`: a `[paths: ...]` list in an issue's body holds no start now. To keep an issue from starting beside another, leave it out of the start order with `tehas order set --only`. A line that sets `TEHAS_OVERLAP_HOLD=1` stops loading with 78; a blank line or 0 is ignored (#1951).

### Adopter action

Take `TEHAS_OVERLAP_HOLD` out of `instance.env` and `optional.env` before updating. To keep two issues apart, run `tehas order set --issues <n> --only` while the first runs.
