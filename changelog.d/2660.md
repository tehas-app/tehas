### Changes

- tsc, TypeScript's native compiler, is pinned in `host/versions.env` (`TSC_VERSION` and `TSC_SHA256`). The sandbox image carries it, `bootstrap.sh user` installs it into `~/tehas/bin`, CI reads the pin from `versions.env`, and the release's `console pins` moves it within its major. The kit's type check now runs in a work cycle's gate and on a host, and finds the pinned tsc on `PATH` even behind another version (#2660).
- `scripts/verify.sh --full` exports `TEHAS_TEST_STRICT=1`, so a missing shellcheck or tsc fails the full gate as it fails CI (#2660).

### Adopter action

Run `./bootstrap.sh user` from the platform checkout after updating, so the host has the pinned tsc. `tehas update` rebuilds the sandbox image, since a pin it reads moved. On a host that works on tehas itself, `.pi/verify-cmd-full` runs `scripts/verify.sh --full`, which now needs tsc: a cycle's gate fails there until the image with tsc is built.
