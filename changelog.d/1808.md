### Changes

- The six `--json` objects that had no contract now have one: `tehas api`,
  `tehas limit`, `tehas drain`, `tehas freeze` and `tehas thaw`, `tehas history`
  and `tehas panel` each have a closed JSON Schema in `api/` and samples the
  commands themselves print, which one test file keeps in step with the code. A
  program that reads one of the objects copies its samples into its own tests,
  as it could already do for `tehas status --json`. A field a schema names that
  the code no longer prints fails the test, so the page and the schemas say what
  the commands print (#1808).
