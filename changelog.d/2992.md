### Changes

- `tehasbot status` reads the shipped issues of the dashboard's `completed` list, and the ones to give `tehas:shipped`, through the tickets port, each poll reading the issues closed since an hour before its last read that answered (a day back the first time), and keeping up to a hundred, newest closed first. After an update the list starts short and fills over a few polls. An issue closed only by a merged pull request of another repository is no longer shipped, and one closed by another repository's unmerged pull request while a merged one of this repository closes it now is. An issue that is reopened stays in the list until newer ones push it out. A read that fails, or names more than a hundred issues closed since it started, keeps the list as it was and says so in `stale` and a `WARN status:` line, and the next poll asks from the same time (#2992).
