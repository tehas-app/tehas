tehas limit: an outside cap on what this factory starts.

A limit caps the cycles running at once and may turn off planning turns and
improvement runs, until it expires or is cleared. A person uses it to keep a
host quiet for a weekend; a program uses it to share model time between
factories. Running cycles are never stopped: a lower limit only holds new
starts. A limit that has expired, or a file that cannot be read, holds every
start until the limit is set again or cleared, so a program that sets a
limit with an expiry and then dies leaves a factory that starts nothing,
not one that runs unlimited. tehas pause is a separate switch: a paused
factory stays paused under any limit.

Usage:
  tehas limit [--json]          show the limit, or "none"
  tehas limit set --cycles N [--plan on|off] [--for SECONDS | --until TIME] [--reason TEXT]
  tehas limit clear

  --cycles N     the most cycles running at once, 0 to 9999. Room for a new
                 cycle is the smaller of N and TEHAS_TICKET_CONCURRENCY,
                 less the cycles running, then the slice and
                 TEHAS_MAX_AWAITING as always
  --plan off     no new planning turn and no improvement run; an answer to a
                 planning question still runs [on]
  --for SECONDS  expire that long from now
  --until TIME   expire then, as 2026-10-17T14:05:00Z
  --reason TEXT  shown as the hold's reason: one line of at most 200
                 characters, control characters become spaces. It is shown
                 on pages that may be public

Setting replaces the whole limit; setting it twice the same way leaves the
same file. Each command prints the limit as it then is:

  limit     1 cycle at once, planning off, until 2026-10-17T14:05:00Z: held for alpha

With --json, {"api": 1, "state": "ok", "cycles": 1, "plan": false,
"until": "...", "reason": "..."}: state is none, ok, expired or unreadable,
and a field without a value is left out.

The settings are loaded here, and the arguments of set, the
reading, the writing and the printing are the console's (console/src/flags.rs).

Exit: 0 shown, set or cleared; 64 a bad argument, which writes nothing; 78
the instance settings are missing or malformed, which writes nothing.
