tehas wiki: the state of the product wiki.

The wiki is built from the product's code, its version tags and its commit
history, and shown at /wiki on the factory's site. This says which build is
current, from which commit, and how far it is behind main: the commits since
its commit and the age, in days, or in months from 60 days. It reads the
product checkout and ~/tehas/wiki, and runs no model and no call to GitHub.
tehasbot wiki writes the same state to ~/tehas/live/wiki.json for the page;
tehas-wiki-status.timer runs it every five minutes.

The wiki is still being built in this release: TEHAS_WIKI=on stops every
command with 78.

Usage: tehas wiki [--json], which prints one object with state, current,
main and behind.

Exit: 0 the state was printed; 64 an argument other than --json; 78 the
wiki is off, or the instance settings are missing or malformed.
