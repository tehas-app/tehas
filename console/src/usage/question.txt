tehas question [<issue>]: the question an issue waits on and its choices, or every question.

A program on the host that answers for a person, such as an industry, reads
here which question a stopped ticket or a planning session waits on, and
the choices it offers, to show them and to answer one with tehas answer.
It reads the state store (state/tehas.db) and nothing else, and changes
nothing.

A planning question offers its options, numbered from 1 as its comment
lists them, and the end of the session. A stop offers the choices it was
asked with: a retry with the issue and its comments, a retry with the
issue text only, or leaving it stopped. A stop asked before the store kept
its choices lists all three, and the poll refuses an answer its comment
does not offer. A reply in words, tehas answer --text, is not listed: a
planning question always takes one.

With no issue it lists the question each issue waits on, and with --after
every question whose number is greater than <id>, the answered and the
withdrawn among them, in number order: --after 0 lists them all. A question's
number is the state store's own, given in order and never reused, so a
program that keeps the greatest number it has seen reads every later
question once.

Usage:
  tehas question <issue>          the question and its choices, one per line
  tehas question <issue> --json   the same as one object
  tehas question                  the question each issue waits on, one per line
  tehas question --after <id>     every question after that number
  tehas question ... --json       the same as one object

Each choice is the word tehas answer takes (retry, retry-text, park,
option:<k>, update, end) and the words a person sees for it:

  #12 waits on its park question, asked at 2026-10-17T14:00:20Z:
    retry-text   Retry with the issue text only
    park         Leave it parked

With --json, {"api": 1, "issue": 12, "question": {"id": 2, "kind":
"park", "comment": 4003, "askedAt": "...", "choices": [{"label": "...",
"choice": "retry-text"}, ...]}}. comment is the id of the comment on the
issue that asked the question, left out when the store has none for it.

A list is one line a question, and with --json {"api": 1, "questions":
[{"id": 2, "issue": 12, "kind": "park", "comment": 4003, "cycle": "12-1",
"askedAt": "...", "choices": [...]}, ...]}, with answeredAt on an answered question and
withdrawnAt on a withdrawn one. cycle is a stop's alone. A planning
question the issue no longer waits on has no choices: its options are kept
only while it waits.

  question 2: #12 park, asked at 2026-10-17T14:00:20Z, withdrawn at 2026-10-17T14:00:50Z

Exit: 0 a question waits, or the list is printed, an empty one too; 1 the
state store refused or is not installed; 3 no question waits on the issue;
64 a bad argument; 78 the instance settings are missing or malformed.

Instance settings (lib/config.sh): TEHAS_REPO.
